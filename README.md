
Simulacion de Ecommerce de Perfumeria,la pagina cuenta con carrito de compras,animaciones,mensajes dinamicos,transiciones,Formulario de compras.

📌 Funcionalidades principales:

Catálogo dinámico: Carga y renderizado asíncrono de productos consumiendo datos en formato JSON nativo.

Gestión de carrito: Sistema de compras en tiempo real con cálculo matemático de subtotales, agrupación por cantidades y prevención de ítems duplicados.

Persistencia de datos: Implementación de localStorage para mantener el estado del carrito activo incluso tras recargar el navegador.

Checkout interactivo: Pasarela de pago simulada con diseño "split-screen" (pantalla dividida), validación estricta de formularios y notificaciones de flujo mediante librerías externas.

💻 Tecnologías y Herramientas:

Lenguajes: JavaScript (ES6+), HTML5, CSS3.

Técnicas: Asincronía (Fetch API, Async/Await), Manipulación del DOM, Flexbox & CSS Grid.

Librerías: SweetAlert2 (manejo de alertas modales).
